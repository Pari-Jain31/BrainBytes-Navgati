# BrainBytes- NavGati 🚍

# 📌 Overview

NavGati is a lightweight, real-time public transport application designed especially for small and medium-sized cities. It provides live bus tracking, estimated arrival times, seat availability insights, and safety features to improve the daily commuting experience.

Our mission is to make public transport reliable, transparent, safe, and accessible while promoting sustainable urban mobility.

# ✨ Key Features

🛰️ Real-Time Bus Tracking – Live GPS-based bus location updates

⏳ Estimated Time of Arrival (ETA) – Accurate arrival predictions

🪑 Bus Occupancy & Seat Availability – AI-assisted estimation

🧭 Route Discovery – Find best routes and nearby bus stops

🌐 Multi-Language Support – Inclusive for diverse users

📶 Offline Route Information – Works even with low connectivity

💬 Chatbot Assistant – Query routes, ETAs, and help

🆘 Emergency SOS (Women Safety) – One-tap emergency alert

🎟️ Digital Bus Passes & Tickets – Paperless commuting

📊 Admin Dashboard – For transport authorities

📝 Feedback System – User suggestions & complaints

🗺️ Trip Planner (Premium) – Smart journey planning

# 🧩 Unique Selling Proposition (USP)

- Tailored for small cities
- Works on 2G/3G networks
- Lightweight app for low-end devices
- Live location via SMS fallback
- AI-based seat verification
- Integrated safety & chatbot support

# Technologies Used

- Google Maps API – Live location & route mapping
- Firebase – Authentication & real-time database
- Google Cloud Platform (GCP) – Backend hosting
- Dialogflow – AI-powered chatbot assistant
- TensorFlow Lite – AI model for seat occupancy estimation
